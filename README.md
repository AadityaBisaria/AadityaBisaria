# Aaditya Bisaria

**AI Engineer — Voice & Agentic Systems | Applied ML**

I build production-grade voice and agentic AI systems end to end: real-time speech pipelines, tool-calling agents, on-device inference, and the evaluation infrastructure that keeps them honest.

Currently AI Engineer at **Prar Labs**, where I own the core intelligence layer behind a voice-first clinical assistant that runs online and offline across mobile, browser, and a hardware hub.

---

## What I work on

- **Real-time voice agents** — LiveKit + Pipecat pipelines with barge-in, streaming output, and latency measured.
- **Agent orchestration at scale** — tool selection across 80+ tools using hybrid dense/BM25 retrieval with RRF fusion, feeding a grammar-constrained small language model for structured intent decoding.
- **On-device / offline inference** — running LFM2.5 (1.2B) locally on a Qualcomm QCS6490 SoC so the assistant keeps working without connectivity.
- **LLM evaluation & observability** — Langfuse tracing, curated eval datasets, prompt versioning, cost monitoring, and human-annotated feedback loops for clinical faithfulness.
- **Clinical ML** — ambient conversation-to-SOAP note generation benchmarked on ACI-Bench, and a fine-tuned 6-lead ECG rhythm-classification foundation model at 0.988 AUROC.
